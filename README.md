# ClipDrop 📋⚡

> Effortless, real-time cross-device clipboard sync and temporary file sharing.

🌐 **Live Website:** [https://clipdrop.is-a.software](https://clipdrop.is-a.software)

---

## ✨ Features

- **Instant Shared Rooms:** Create or join a room in seconds with a simple code or QR code.
- **Cross-Device Clipboard Sync:** Seamlessly copy and paste text, code snippets, and links between your phone, laptop, and tablet.
- **Fast File Drops:** Drag and drop files, photos, and media to share them instantly without registration or sign-in.
- **Clean & Fast UI:** Designed with a modern, responsive layout, dark/light theme support, and zero friction.
- **Edge Powered:** Low-latency dynamic synchronization backed by Cloudflare edge functions.

---

## 🚀 Live Demo

Try it out directly at:  
👉 **[clipdrop.is-a.software](https://clipdrop.is-a.software)**

1. Open the website on any device.
2. Click **Create room** (or enter a room code to join an existing one).
3. Drop text, links, or files — they immediately sync across all devices in the room.

## 🛠️ Local Development

### Prerequisites
- Node.js 18+ (Node.js 20+ recommended)
- npm

### Setup

1. **Clone the repository:**
   `ash
   git clone https://github.com/SuperStarkid/ClipDrop.git
   cd ClipDrop
   `

2. **Install dependencies:**
   `ash
   npm install
   `

3. **Build the site:**
   `ash
   npm run build
   `
